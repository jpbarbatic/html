🌐 Implantación de Aplicaciones Web (IAW)

Recursos, contenidos y enlaces esenciales para 2º de ASIR

📚 Bloques de Contenidos

1. Servidores Web

  • Protocolos HTTP/HTTPS y DNS.
  • Apache y Nginx (Hosts virtuales).
  • Seguridad SSL/TLS (Let's Encrypt).

2. Lenguajes de Scripting

  • Configuración de PHP (php.ini).
  • Sintaxis y conexión a bases de datos.
  • Alternativas (Node.js / Python).

3. Gestores de Contenido

  • Despliegue de CMS (WordPress, Drupal).
  • Mantenimiento y plantillas.
  • Copias de seguridad y migración.

4. Automatización

  • Contenedores con Docker y Compose.
  • Control de versiones con Git.
  • Flujos de trabajo en GitHub/GitLab.
